Animation philosophy: Motion is intentional, not decorative. Every animation communicates state or depth — never movement for its own sake. Physics-based easing (cubic-bezier) over linear. Smooth > flashy.

09
Rules of the System
Always do
  • Use Cormorant for all headings and prices
  • Use gold (#c9a96e) as the sole accent color
  • Keep borders at 1px, sharp (0px radius)
  • Use opacity ramps for text hierarchy
  • Apply cubic-bezier easing on all transforms
  • Stagger reveals with 0.1s delay per child
  • Keep section padding at 140px
  • Use SVG line art for product placeholder icons
  • Eyebrow label before every section title
  • Custom cursor on all pages
Never do
  • Use #6c5ce7, #a78bfa, #38bdf8 or any bright purple/blue
  • Use border-radius > 2px on cards/buttons
  • Use Inter, Roboto, or system fonts
  • Use neon glow or heavy drop shadows
  • Use color as decoration (only as meaning)
  • Add animation that doesn't serve depth or state
  • Use linear easing on transforms
  • Mix light and dark backgrounds in same section
  • Use font-weight 600 or 700 anywhere
  • Use rounded corners on single-sided borders
