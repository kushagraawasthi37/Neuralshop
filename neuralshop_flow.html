React Query — Server State
Products
  • products list ["products", params]
  • product detail ["product", id]
  • recommendations ["rec", type, id]
  • staleTime: 5 min
Cart
  • cart data ["cart"]
  • cart summary ["cart", "summary"]
  • Optimistic updates on mutate
  • Rollback on error
Orders
  • order list ["orders", params]
  • order detail ["order", id]
  • Invalidate on create/cancel
Reviews
  • product reviews ["reviews", productId]
  • Invalidate on submit/edit
  • Optimistic helpful count
Wishlist
  • wishlist ["wishlist"]
  • check item ["wishlist", "check", id]
  • Optimistic toggle
Analytics
  • dashboard ["analytics", "dashboard"]
  • sales ["analytics", "sales", params]
  • Parallel queries, all tabs
Custom Hooks
useAuth()
Auth state, login/logout/refresh token actions
useCart()
Cart CRUD with optimistic updates and guest migration
useProduct(id)
Single product query with 5-min stale cache
useProducts(params)
Filtered + paginated product list query
useOrder(id)
Order detail + create/cancel mutations
useWishlist()
Wishlist CRUD with optimistic heart toggles
useCoupon()
Validate + apply coupon with error messaging
usePagination()
Page, skip, limit, total-pages calculation
useFilters()
Filter state with update/remove/clear actions
useDebounce()
Debounced search input — 400ms delay
useLocalStorage()
Sync state to localStorage with JSON parse/stringify
useForm(schema)
React Hook Form + Zod resolver wrapper
